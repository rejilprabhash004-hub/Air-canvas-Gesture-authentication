Only sites you add here are listed. This is a local status preference, not access control.

For an enabled site, opening the extension popup records a local event containing only the timestamp, exact hostname, and status. It never records paths, query strings, page content, or unconfigured sites. The latest 200 checks are kept in extension storage; history is not encrypted and is not sent to SecureAir's Python dashboard. You can clear it below.
